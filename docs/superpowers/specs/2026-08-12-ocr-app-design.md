# OCR 截图识字桌面应用 — 设计文档

日期：2026-08-12
状态：待用户审阅

## 1. 目标与背景

个人日常使用的 Windows 桌面工具：**框选屏幕区域 → 自动识别其中的文字 → 用户自己选择复制哪部分**，体验类似微信/QQ 截图识字。

明确非课程设计，按"好用顺手、隐私安全"设计。

## 2. 技术决策

| 决策 | 选择 | 理由 |
|---|---|---|
| OCR 引擎 | 可插拔：本地 RapidOCR（默认离线）+ 百度 OCR（云端增强） | 屏幕文字清晰时离线免费够用；复杂版面（表格/小字/模糊/手写）切云端提高准确率 |
| GUI 框架 | PySide6 | 截图遮罩、浮窗、文字展示更精致，接近微信手感 |
| 触发方式 | 全局热键 + 系统托盘 + 窗口按钮，三者都有 | 托盘常驻 + 热键随时呼出，按钮作兜底 |
| 文字输出 | 浮窗快速复制 + 主窗口历史 | 浮窗贴选区旁即时复制，主窗口留痕回看 |
| API key 存储 | Windows 凭据管理器 | 不写进代码、不落明文文件，系统级加密 |

## 3. 架构

单进程 PySide6 应用，OCR 跑后台线程（QThread）避免界面冻结。

```
app/
├── main.py              # 入口：QApplication + 系统托盘 + 全局热键注册
├── config.py            # 非敏感配置持久化：热键、默认引擎
├── ocr/                 # 可插拔识别引擎
│   ├── base.py          # OCRBackend 接口：recognize(image_path) -> str
│   ├── rapid.py         # 本地 RapidOCR（默认）
│   ├── baidu.py         # 云端百度 OCR（通用文字识别）
│   └── manager.py       # 引擎选择/切换、后台线程执行
├── capture/
│   ├── overlay.py       # 全屏截图遮罩：半透明、拖拽框选、Esc 取消
│   └── screen.py        # 选区截屏、保存临时图片
├── ui/
│   ├── result_popup.py  # 浮窗：文字选中复制 + 复制全部 + 云端增强
│   ├── history_window.py# 主窗口：历史列表 + 回看复制
│   └── settings_dialog.py # 设置：热键、默认引擎、百度 key 输入框
├── security/
│   └── creds.py         # Windows 凭据管理器读写（ctypes CredWrite/CredRead）
└── storage/
    └── history.py       # 历史持久化 JSON
```

## 4. 数据流

```
触发（热键 / 托盘 / 按钮）
  → 截图遮罩全屏出现（半透明变暗）
  → 鼠标拖拽框选区域，释放
  → screen.py 截取该区域为图片
  → 后台 QThread 跑当前引擎 OCR
  → 浮窗贴在选区旁：
       - 文字可局部选中（Ctrl+C）
       - "复制全部"按钮
       - "云端增强"按钮：切换百度重新识别并替换文本
  → 同时写入主窗口历史 + JSON 持久化
```

## 5. 界面交互

- **遮罩**：全屏无边框、半透明变暗，拖拽出选区，释放即截取；Esc 取消
- **浮窗**：`QPlainTextEdit` 展示文本（可选中复制）+ "复制全部" + "云端增强" + 关闭
- **主窗口历史**：每条显示 缩略图 + 时间 + 首行文字 + 所用引擎；点击回看/复制；删除单条、清空全部
- **托盘菜单**：框选截图 / 打开历史 / 设置 / 退出
- **全局热键**：默认 Ctrl+Alt+A，可在设置修改；用 Windows 原生 `RegisterHotKey`（ctypes 调用）注册，不额外装 keyboard/pynput 依赖，应用退居托盘后仍生效

## 6. 配置与密钥

- 非敏感配置（热键、默认引擎）存本地 JSON 配置文件
- 百度 OCR 凭据 = **API Key + Secret Key**（百度智能云控制台创建应用后获得），设置对话框提供**两个输入框**填写，不写入代码
- 凭据经 `security/creds.py` 存到 **Windows 凭据管理器**（ctypes 调 CredWrite/CredRead，不额外装库），应用启动时自动读取

## 7. 持久化

- 历史存 JSON（配置目录 `~/.ocr_app/history.json`），保留最近 100 条
- 每条：时间戳、选区截图（存缩略图文件）、识别文本、所用引擎
- 历史窗口可回看已保存的截图与文本

## 8. 错误处理

| 场景 | 处理 |
|---|---|
| 本地引擎模型加载失败 | 提示并建议切换云端 |
| 百度 key 缺失 / 未填 | 浮窗提示去设置填写，回退本地 |
| 百度网络错误 / 超时 | 浮窗报错，回退本地结果 |
| 选区无文字 | 浮窗显示"未识别到文字" |
| 热键注册冲突 | 日志警告，回退托盘/按钮触发 |

## 9. 测试

- OCR 后端：用 PIL 生成含中文/英文的测试图片，断言返回文本（本地 + 百度 mock）
- 历史存储：增/删/清空/加载 JSON 的单元测试
- 遮罩选区几何：拖拽坐标归一化逻辑纯函数单测
- 手动验证主流程：热键呼出 → 框选 → 识别 → 复制 → 历史回看
