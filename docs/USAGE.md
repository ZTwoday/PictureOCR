# 使用说明

## 启动
在项目根目录运行：`.venv/Scripts/python main.py`

## 基本用法
1. 按全局热键 **Ctrl+Alt+A**（或托盘 → 框选截图）呼出遮罩
2. 按住左键拖拽框选屏幕区域，松开即自动识别
3. 浮窗显示识别文字：
   - 鼠标选中部分文字后 Ctrl+C 复制
   - 点"复制全部"复制全部文本
   - 点"云端增强"用百度重新识别（更准，需先配置 key）
4. 托盘 → 打开历史：回看之前的识别结果，可删除/清空
5. 托盘 → 设置：改热键、默认引擎、百度 API Key / Secret Key

## 修改热键
设置对话框改"全局热键"，格式如 `Ctrl+Alt+A`、`Ctrl+Shift+B`，重启生效。

## 数据位置
- 配置与历史：`C:\Users\<你>\.ocr_app\`
- 百度凭据：Windows 凭据管理器（不进代码、不落明文）

## 百度 OCR 配置
1. 百度智能云控制台创建应用，获取 API Key 和 Secret Key
2. 设置对话框填入两个 key，保存后存入 Windows 凭据管理器
