# 使用说明

## 启动
在项目根目录运行：`.venv/Scripts/python main.py`
（或双击桌面的「截图识字」快捷方式）

## 基本用法
1. 启动后出现「截图识字」主窗口
2. 点主窗口的 **识别文字** 按钮，或按全局热键 **Ctrl+Alt+A**
3. 屏幕定格变白后，按住左键拖拽框选屏幕区域，松开即自动识别
4. 识别完成后主窗口自动弹出，文字显示在文本框里（可直接修改错字、调整段落）：
   - 鼠标选中部分文字后 Ctrl+C 复制
   - 点「复制全部」复制全部文本
   - 点「还原」恢复刚才识别出的原文
   - 点「云端增强」用百度重新识别（更准，需先配置 key）
5. **普通截图**：点主窗口的 **截图** 按钮（或托盘菜单「截图」），框选区域后弹出预览窗口，顶部点「保存」选择位置保存，或点「复制到剪贴板」。
6. 想继续识别，直接再点「识别文字」即可，无需关闭任何窗口
7. 托盘 → 设置：改热键、默认引擎、百度 API Key / Secret Key

## 修改热键
设置对话框改"全局热键"，格式如 `Ctrl+Alt+A`、`Ctrl+Shift+B`，保存后即时生效。

## 数据位置
- 配置与截图临时文件：`C:\Users\<你>\.ocr_app\`
- 百度凭据：Windows 凭据管理器（不进代码、不落明文）

## 百度 OCR 配置
1. 百度智能云控制台创建应用，获取 API Key 和 Secret Key
2. 设置对话框填入两个 key，保存后存入 Windows 凭据管理器
