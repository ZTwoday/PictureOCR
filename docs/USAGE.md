# 使用说明

## 启动
在项目根目录运行：`.venv/Scripts/python main.py`
（或双击桌面的「截图识字」快捷方式）

## 基本用法
1. 启动后出现「截图识字」主窗口
2. 点主窗口的 **框选截图** 按钮，或按全局热键 **Ctrl+Alt+A**
3. 屏幕变暗后，按住左键拖拽框选屏幕区域，松开即自动识别
4. 识别完成后主窗口自动弹出，文字显示在文本框里：
   - 鼠标选中部分文字后 Ctrl+C 复制
   - 点「复制全部」复制全部文本
   - 点「云端增强」用百度重新识别（更准，需先配置 key）
5. 想继续截图，直接再点「框选截图」即可，无需关闭任何窗口
6. 托盘 → 设置：改热键、默认引擎、百度 API Key / Secret Key

## 修改热键
设置对话框改"全局热键"，格式如 `Ctrl+Alt+A`、`Ctrl+Shift+B`，保存后即时生效。

## 数据位置
- 配置与截图临时文件：`C:\Users\<你>\.ocr_app\`
- 百度凭据：Windows 凭据管理器（不进代码、不落明文）

## 百度 OCR 配置
1. 百度智能云控制台创建应用，获取 API Key 和 Secret Key
2. 设置对话框填入两个 key，保存后存入 Windows 凭据管理器
